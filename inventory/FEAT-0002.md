# Global never-reuse ID sequence and retired ledger

IDs are drawn from a single global, monotonically increasing sequence shared by every type. A number is never reused: allocation takes the max over live docs, the `_retired.md` ledger, and every relation map (struck or not), so a closed doc's tombstone still reserves its number. `retire` appends to the sorted ledger; `verify` rejects reuse and duplicate numbers.

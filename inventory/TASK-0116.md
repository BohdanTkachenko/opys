# engine: ttl, max_visits, the stuck predicate, `verify --fix`, exit 3

[FEAT-0108 — Time-aware verify: stuck, visits, `--fix`](FEAT-0108.md), [ADR-0101 — Verify observes time: stuck, visits, `--fix`, and exit code 3](ADR-0101.md).

Spec:

- Config: `[types.X.ttl]` status to humantime duration; `[types.X.max_visits]`
  status to `{ limit, then }`. Validation: targets are declared statuses; when
  transitions exist, the `ttl` target and `then` have an edge back to at least
  one non-terminal status.
- `observe::stuck(doc, now, cfg) -> Option<Observation>` and
  `observe::overflow(doc, cfg)`; one module, the only place the clock is read,
  through `now()` which honours `OPYS_NOW`.
- `set-status` refuses the entry that would exceed `limit`, naming `then`.
- Verify: an `Observations` block after problems; exit 3 iff observations and
  no problems. `--fix` performs the transitions through `set_status::core`
  (bypassing the visits guard for the `then` move), runs the sync pass, then
  re-verifies and exits on the remainder. `verify` becomes lock-taking in
  `--fix` mode.
- The binary's exit mapping and CLAUDE.md's exit-code contract gain code 3.
- Tests use `OPYS_NOW` and never sleep.

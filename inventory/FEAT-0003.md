# Canonical closed frontmatter

Frontmatter is a closed set: the reserved keys (`id`, `status`, `tags`, the relation maps, timestamps) plus the type's declared `[fields.*]` — unknown keys fail `verify`. Serialization is canonical (core fields first, the rest alphabetical, minimal quoting) and the store invariant is `reconstruct(decompose(doc)).to_text() == doc.to_text()`.

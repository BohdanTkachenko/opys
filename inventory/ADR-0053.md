# Everything open source; sell connectivity, hosting, and convenience

## Context

The commercial model went through several drafts: reselling AI subscriptions
(rejected — ToS-fraught, margin-thin, competes with the vendors opys
orchestrates), a BYO-cloud provisioning tier where users hand over cloud
credentials (rejected — monetizes the segment least willing to pay, at the
highest support cost per dollar, and makes us custodian of spend-capable
keys), and feature-gated open-core (rejected — poisons the funnel and rots the
"100% open source" claim). The proven shapes for this product are Nabu
Casa/Home Assistant (paid remote access to a self-hosted system), Ghost
(hosted-for-money, self-host community-supported), and Cloudways (managed
compute resale on upstream providers — later acquired by DigitalOcean).
Inference and VMs are inputs, not products: SaaS with token COGS and VM COGS.

## Decision

The entire stack — CLI, engine, node daemon, orchestrator, web UI, relay
server, planning assistant — is open source and fully functional self-hosted.
Revenue is convenience, never capability:

- **Connect** (~$5/mo): hosted relay + web/phone access to nodes on your own
  hardware. Typed API only ([ADR-0052 — The hosted plane is blind and unprivileged](ADR-0052.md)). The Nabu Casa wedge and the funnel
  bridge — protect it.
- **Hosted** (~$30/mo base + metered compute): we run the whole environment on
  our upstream account (one substrate, [FEAT-0060 — Hosted environments: managed development VMs](FEAT-0060.md)); SSH and browser terminal
  included. The mainstream entry door — a user who has never touched a
  terminal starts here: web signup → VM → connect GitHub.
- **Team** ($/user/mo, later): the same server doing three more jobs — union
  view across a node mesh, id-lease acceleration, bot committer ([FEAT-0063 — Teams: node mesh, union view, per-seat plan](FEAT-0063.md)).
- Metered management-plane AI credits on top ([ADR-0054 — Bundle management-plane AI; execution-plane AI is bring-your-own](ADR-0054.md)).

Not offered: provisioning into customer cloud accounts (the compliance segment
gets an enterprise self-host support contract someday instead), unlimited
plans of anything metered, feature gating. Self-hosting gets one supported
install path (docker-compose and/or a Nix flake + SELF_HOSTING.md), a
community forum, and no SLA.

## Consequences

- Compute-included tiers must meter: flat pricing maps to exactly one bounded
  VM; swarms ([FEAT-0062 — Worker pools: SSH fleet and managed swarm](FEAT-0062.md)) are a usage line item (passthrough + margin), or the
  heaviest users are subsidized by design.
- Hosted-tier ops burden is accepted as the cost of the mainstream door:
  card required day one, VM-per-customer isolation, CPU/egress caps, dead-man
  TTLs (agents + rentable compute attracts miners).
- A Hosted customer can eject to self-host with their data intact — same
  binaries, same files — which is itself a selling point.
- The relay being open source means someone can rehost it commercially; the
  mitigation under consideration is the [ADR-0056 — License split: Apache-2.0 core, AGPL server components](ADR-0056.md) license split.

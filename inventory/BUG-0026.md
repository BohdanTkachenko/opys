# Corrupt _retired.md is silently read as an empty ledger

## Reproduction
Introduce a one-character typo in `_retired.md` (e.g. a `--` fence instead of `---`). `retired::read()` swallows the parse failure and falls back to the legacy ledger (usually absent, so empty): reservations vanish, `opys new` can reuse retired numbers, and the next retire rewrites the ledger from the empty read — permanently dropping every previously reserved id. The fallback should be a hard error (or at least a verify problem).

## Tasks
- [ ] make an unparseable `_retired.md` an `OpysError` instead of an empty fallback
- [ ] have `verify` flag a ledger that fails to parse
- [ ] test that a corrupt ledger blocks allocation rather than resetting it

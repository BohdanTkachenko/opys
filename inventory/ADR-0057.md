# One announcement, at the relay milestone

## Context

A launch message effectively fires once. The repo and crates are already
public (GitHub, crates.io v0.12.0) but undiscovered — nothing is hidden by
waiting, so the announcement is purely a marketing event to be timed. The
space (agent task orchestration) is white-hot and every month ships more
vendor-locked versions of the loop; the mitigation for delay is scope
discipline, not hurry. The strongest single message is not "a CLI + markdown
registry" (announceable today) but the concrete product: watch and steer your
agent fleet from anywhere, 100% open source, self-host or pay for zero-config.

## Decision

Defer the announcement to the [FEAT-0059 — Relay and Connect: remote access to your nodes](FEAT-0059.md) (relay + Connect) milestone, with
[FEAT-0058 — opys-server: the always-on node](FEAT-0058.md) as its self-hosted half — a live dashboard demo, a price, and a
self-host path. Message the concrete layer, not the endgame: opys is the
*neutral, open coordination plane* for whatever agents you already use —
never "stop using Claude/Codex" (that framing invites platform war with the
vendors opys orchestrates; neutrality makes every vendor a listed integration
instead). The autonomous-fleet loop ([FEAT-0061 — Orchestrator: agents pick up registry work](FEAT-0061.md)/[FEAT-0062 — Worker pools: SSH fleet and managed swarm](FEAT-0062.md)) is the named
roadmap teaser, not the headline.

Before the announcement: git history is erased (a fresh root commit) and all
inventory/docs are swept and sanitized — internal pricing drafts, business
notes, and this planning trail are trimmed to what the public repo should
carry ([CHORE-0040 — Docs sweep before the announcement](CHORE-0040.md) tracks the sweep; [TASK-0047 — Announcement assets: demo recording and comparison table](TASK-0047.md) the assets).

## Consequences

- [CHORE-0038 — Write the 0.12.0 changelog and deprecate the orphaned opys-core crate](CHORE-0038.md)/[CHORE-0040 — Docs sweep before the announcement](CHORE-0040.md)/[TASK-0047 — Announcement assets: demo recording and comparison table](TASK-0047.md) rescope to the new milestone; nothing else
  blocks on marketing.
- Stages after the relay (MCP [FEAT-0042 — Remote MCP: manage the registry from shell-less hosts](FEAT-0042.md), orchestrator [FEAT-0061 — Orchestrator: agents pick up registry work](FEAT-0061.md), swarm
  [FEAT-0062 — Worker pools: SSH fleet and managed swarm](FEAT-0062.md), teams [FEAT-0063 — Teams: node mesh, union view, per-seat plan](FEAT-0063.md)) become *second* announcements — launch again on
  every major layer.
- Until then the public repo keeps quietly improving; discoverability before
  the announcement is fine and costs nothing.

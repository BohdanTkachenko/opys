# Reference reconciliation and prose linkify

The `references` relation map is auto-maintained on every write: bidirectional between live docs, titles kept fresh, sorted by number; a closed doc leaves a struck-through tombstone. Bare `PREFIX-NNNN` mentions in body prose are turned into markdown links, skipping code spans and fences. Runs as part of the auto-sync pass after every mutating command, or `opys sync` after hand edits.

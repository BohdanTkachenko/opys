# Directional blockers

`opys block <id> --by <id>` records a directional relation on the same ID-to-title machinery as `references`: `blocked_by` on the blocked side, the inverse `blocks` on the blocker. Blocking a doc whose type has a `blocked` status auto-sets it; `unblock` reverts when no blocker or reason remains.

## Test plan
- [x] block writes both directions and sets the blocked status — `cli::block_links_both_directions_and_sets_blocked_status`
- [x] unblock removes the link and reverts the status — `cli::unblock_removes_link_and_reverts_status`
- [x] closing a blocker strikes the relation and reserves its id — `cli::close_strikes_blocker_and_reserves_id`

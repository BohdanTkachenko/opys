# agent-rules writes relative to cwd, not the project root

## Reproduction
Run `opys agent-rules --tool cursor` from a subdirectory of a project: the file lands at `sub/deep/.cursor/rules/opys.mdc` instead of the project root, because `run` uses `ctx.root` (default `.`) while every other command resolves the root via `find_root`. The existing test runs from the root and cannot catch it.

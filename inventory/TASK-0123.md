# engine: the atomic claim batch

A claim must be one all-or-nothing batch, so that two dispatchers racing for the
same document cannot both win. Asked for by the kobzar split: kobzar owns the
policy of who claims what, but the primitive that makes a claim atomic is the
tracker's.

Spec:

- One invocation moves a document into its working status, sets the field that
  records who claimed it, and appends a log line, as a single batch: either all
  three land or none do. The batch already exists (`commands::apply_batch`,
  [TASK-0114 — engine: remove `query --write` and the writable blocks projection](TASK-0114.md));
  what is missing is that a status change, a field write and a log entry can be
  named together in one command.
- The state machine is what settles the race. A second claimant arrives when the
  document has already left the pickable status, so its transition is not a
  declared edge and the whole batch is refused with exit 2, writing nothing.
  That is the guarantee to test, not a lock: the inventory flock only serializes
  the two invocations, it does not decide which one is legitimate.
- Decide and record whether this is a new verb (`opys claim <id> --as <who>`) or
  a general "several actions, one batch" form that a claim is an instance of.
  The kobzar session recommends the general form, because a dispatcher needs the
  same atomic shape for releasing and completing a document, and a claim verb
  would put dispatcher vocabulary into the tracker. That is the way to lean;
  the counterweight is that a general form needs a grammar, and a claim is the
  one composite write agents make constantly.
- The field that records the claimant is an ordinary declared field, not a new
  reserved key: opys stores who claimed a document, and knows nothing else about
  agents ([ADR-0051 — Files and git are the only truth; the server is a view](ADR-0051.md)).
- The node exposes the same batch as one typed action, so a dispatcher over HTTP
  gets the same atomicity as one over the CLI.
- format.md documents the batch and the race it settles; the skill says a claim
  is one command.

# query --write can relocate files outside the inventory base

## Reproduction
`opys query --write --no-sync "UPDATE docs SET path='../../../../tmp/FEAT-0001.md' WHERE id='FEAT-0001'"` — the write-gate only plan-guards the statement kind, verify only checks the file *stem* matches the id, and `flush_plan` joins the stored path onto the base with no containment check, so flush renames/writes the file outside the inventory (arbitrary path write). Also unguarded: direct DML against `retired` (injects reservations that persist) and snapshot columns like `orig_text`/`num`/`dkey`.

## Tasks
- [ ] reject flush-plan paths that escape the base dir (canonicalize + prefix check)
- [ ] restrict `--write` DML to the authoritative user-facing tables/columns, or verify-check `retired` mutations
- [ ] key the before/after verify diff on doc id, not rendered messages containing mutable paths

# Retire the TUI; the web UI over the server is the human surface

## Context

The TUI ([FEAT-0020 — Terminal UI board](FEAT-0020.md)) serves a human sitting in a terminal on the machine where
one inventory lives. The actual deployment topology is different: agents run on
a dedicated server, each in its own git worktree, and the human drives them
remotely — usually from a browser (remote Claude, a phone). The maintainer does
not use the TUI; pre-announcement, that is the strongest product signal
available. Structurally, worktree-per-agent means one project is N diverging
corpora, and a single-corpus terminal board can never show that. Maintaining
two human surfaces (TUI + web) would split polish across the one that fits the
2010s solo-dev pattern and the one that fits how agent fleets are actually run.

The recent read-mostly refactor (TASK-0045, closing BUG-0031) was the right
preparation in hindsight: it moved the TUI to exactly the model the web client
will use — render board state, route every write through a real command core —
so that work transfers rather than being wasted.

## Decision

Retire the TUI before the announcement. `opys tui`, the `tui` feature flag, and
the `opys-tui` crate are removed ([TASK-0065 — Remove the opys-tui crate](TASK-0065.md)); git history preserves the code.
The human surface becomes the web UI served by the always-on node
([FEAT-0058 — opys-server: the always-on node](FEAT-0058.md)), reachable locally for free and remotely via the relay
([FEAT-0059 — Relay and Connect: remote access to your nodes](FEAT-0059.md)). The ssh niche is covered by `watch opys list` / `opys query`.

## Consequences

- [FEAT-0020 — Terminal UI board](FEAT-0020.md) goes to `wontfix` with this ADR as the reason; the remaining
  TUI test-plan items and the README screenshot task die with it.
- The workspace loses the ratatui/notify/instability dependency surface from
  `--all-features` CI (notify returns later inside the server crate); the MSRV
  floor may drop — recheck when the crate is removed.
- Announcement assets ([TASK-0047 — Announcement assets: demo recording and comparison table](TASK-0047.md)) rescope from a TUI GIF to the web UI demo.
- No human surface exists between the removal and [FEAT-0058 — opys-server: the always-on node](FEAT-0058.md) landing; the CLI
  (`list`/`query`/`stats`) is the interim, which matches actual current usage.

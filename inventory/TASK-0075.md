# opys-server: systemd install, docs, and M1 closeout

The last mile: run the server as a service, document everything, and close
out [FEAT-0058 — opys-server: the always-on node](FEAT-0058.md).

Spec:

- `opys-server install <ROOTS…> [--bind <ADDR>]`: write
  `~/.config/systemd/user/opys-server.service` —
  `ExecStart=<canonical path of the current executable> run <roots…> --bind
  <addr>`, `Restart=on-failure`, `[Install] WantedBy=default.target` — then
  print the `systemctl --user daemon-reload && systemctl --user enable --now
  opys-server` instructions (print, don't execute). Refuse to overwrite an
  existing unit unless `--force`. `uninstall` removes the unit file and
  prints the disable commands. On a non-systemd platform (no
  `$XDG_CONFIG_HOME`/systemd), print manual-run instructions and exit 0.
  Note in the docs that NixOS/home-manager users should declare the service
  instead (one-paragraph example in the README section).
- README.md: a new "The always-on node (`opys-server`)" section — install,
  run, what the dashboard shows, the port, the AGPL note, and the guardrail
  sentence ("the API is typed; the server cannot execute arbitrary
  commands"). Update AGENTS.md/CLAUDE.md likewise (brief).

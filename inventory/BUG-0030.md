# history attributes every revision to the wrong commit

## Reproduction
Change a doc in commit C, then make five unrelated commits. `opys history <id>` shows HEAD's hash/date/author for the doc's latest state: walking newest-to-oldest, `collect` in `src/commands/history.rs` emits a revision at the first (newest) commit whose blob differs from the previously emitted one — i.e. the newest commit while the content was current, not the one that introduced it. Correct approach: diff each commit against its first parent and attribute to the child. Also: `find_blob` matches the basename anywhere in the tree (shadowing + O(tree × history) walks) instead of pruning to the inventory base.

# engine: blocked is derived; remove the blocked status machinery

[ADR-0099 — Lifecycle is config: transitions, history, derived blocked, priority](ADR-0099.md) decision 3.

Spec:

- Remove the auto-set in `block::core`, the `blocked_from` reserved key and
  its restore in `unblock`, and the `blocked_reason` fields plus the
  `require_any` rule from the shipped config. `block`/`unblock` write the two
  relation maps and nothing else.
- `DocType` gains `releases_blocks: Vec<String>` (validated against statuses).
  `refs::live_blockers(doc, corpus)` returns the non-struck `blocked_by`
  entries whose target exists and whose status is not in the target type's
  `releases_blocks`. A struck entry or a missing target is not live.
- `list --blocked` / `list --unblocked` filter on it. The board's blocked count
  uses the same function through the API.
- Remove `blocked` from `task`/`bug`/`chore` in the shipped config and the
  `init` template. Migration for this inventory: documents at `blocked` move to
  `todo` and drop `blocked_from`; add a paragraph to
  `docs/migration-history.md`.
- format.md: the Blockers section loses the auto-set paragraph and gains the
  derived definition and `releases_blocks`.

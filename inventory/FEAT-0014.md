# JSONL import

`opys import --type <T> file.jsonl` bulk-creates documents from one JSON object per line (`title` and `body` special-cased, everything else frontmatter). The whole batch shares one ID allocation and one sync, and it is transactional: any rejected record aborts the batch with nothing written. This inventory was bootstrapped with it.

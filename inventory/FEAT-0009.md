# verify: the CI gate

`opys verify` is the integrity check the whole design leans on: ids, references, statuses, rules, sections, frontmatter, stats queries. Content problems are collected into a list and all printed at once — exit `1` — never turned into hard errors; real failures (bad flags, IO, missing config) exit `2`. Wire it into CI so hand edits and agent writes are both gated.

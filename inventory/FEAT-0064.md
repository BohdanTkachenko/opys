# Planning assistant: AI over the typed API

The native AI surface in the web/mobile UI — not a chatbot in a sidebar, but
an agent whose tools are the typed opys API itself: create feature docs,
decompose an epic into linked tasks, set relations and blockers, draft
test-plan sections per the type's schema, run SELECT queries over the corpus,
summarize what the fleet did overnight, triage a failing verify. Because its
writes go through the same command cores and rules engine as the CLI, its
output is *schema-validated by construction* — it cannot produce a malformed
doc. On mobile it is the primary input method: you talk, documents appear in
the registry, agents pick them up ([FEAT-0061 — Orchestrator: agents pick up registry work](FEAT-0061.md)).

Per [ADR-0054 — Bundle management-plane AI; execution-plane AI is bring-your-own](ADR-0054.md):

- Ships in the open-source UI with a bring-your-own API key (full capability
  self-hosted — [ADR-0053 — Everything open source; sell connectivity, hosting, and convenience](ADR-0053.md)'s no-gating rule).
- Paid tiers bundle a metered credit allowance so it works with zero key
  setup — the convenience being sold, aimed at the persona who will not
  create an API key at a second company.
- Model access is API-key only — the user's key or our allowance; never
  consumer-subscription tokens found on a Hosted VM.
- Privacy: the hosted assistant is a consented, per-feature exception to
  relay blindness ([ADR-0052 — The hosted plane is blind and unprivileged](ADR-0052.md)) — using it sends the docs it reads through our
  plane to the model vendor, disclosed in place; node-side inference with a
  user key is the E2E-preserving alternative.

## Test plan
- [ ] the assistant cannot create a doc that fails verify (rules run on its writes like any CLI write)
- [ ] a spoken/typed feature request becomes a feature doc plus linked tasks with correct references
- [ ] BYO-key path works fully self-hosted with the hosted allowance disabled
- [ ] credit metering cuts off at the cap and degrades to BYO-key gracefully
- [ ] hosted-path disclosure is shown before the first send; node-side mode sends nothing through the relay

- Conversation persistence: transcripts are *not* registry documents — where

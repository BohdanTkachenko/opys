# The terminal-modern web UI redesign

The node's web UI, restyled end to end as "terminal-modern": dark-first with
a cyan→violet accent pair, monospace for everything data-shaped, a status-tone
and type-tone colour engine (semantic hues for universal words, deterministic
hashes for project vocabulary, so no lifecycle is invented), an inline SVG icon
set, dot-grid texture with layered shadows, a glass sidebar, toolbar filters
with a `/` shortcut, designed empty states, centered reading measures on
ultrawide monitors, and Obsidian-calibre prose typography on the document view.
Zero external requests and `prefers-reduced-motion` are preserved throughout.

Shipped across the `ui-redesign` branch (PR #23), verified by rendering every
view in a real browser in both themes from the embedded bundle.

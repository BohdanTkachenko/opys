# retire leaves inbound references dangling and the corpus failing verify

## Reproduction
With a task referencing FEAT-000N, run `opys retire FEAT-000N` — the doc is deleted without striking inbound references (unlike `close`) and the auto-sync pass does not repair them, so `opys verify` immediately exits 1 with "reference does not resolve" plus a `requires_link` violation. A successful mutating command should not leave the corpus red with no warning. Related polish: `--reason` is mandatory but persisted nowhere (only echoed to stdout).

## Tasks
- [ ] strike (or strip) inbound references as part of retire, like close does
- [ ] persist the reason (ledger column) or make the flag optional
- [ ] integration test: retiring a referenced doc keeps verify green

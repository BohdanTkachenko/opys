# Keyboard navigation on the board: columns, cards, projects

The board is a keyboard surface. The cursor is *real focus* on a card, so the
selection is the focus ring, Enter opens the card as the link it is, Tab still
works, and a screen reader agrees about what is selected. Left/Right move it
between columns (the row clamps to the column's length), Up/Down between
cards, Home/End to a column's ends. The first press only reveals the cursor,
where it last was, rather than moving away from a card nobody could see was
selected. PageUp/PageDown switch the board to the previous/next project in the
sidebar's order.

Ctrl/⌘+P and `/` belong to the shell and open the omnibox from any view
([FEAT-0098 — The omnibox: a fuzzy finder over tickets, from the header](FEAT-0098.md)). A legend at the toolbar's far end names the keys and hides
under 62rem, where there is no keyboard worth the space. Nothing is captured
while typing in a field, and a reload that keeps the card keeps the cursor.

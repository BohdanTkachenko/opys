# Bulk ID lists and stdin piping

Every mutating command takes a comma-separated id list, or `-` to read ids from stdin — so `opys list --format ids | opys close -` composes. Bulk application is best-effort: failures are reported per id and the rest proceed.

## Test plan
- [x] comma lists move several docs at once — `cli::bulk_set_status_moves_several_features_with_a_comma_list`
- [x] `-` reads ids from stdin — `cli::bulk_reads_ids_from_stdin_with_dash`
- [x] a list pipe into close works end-to-end — `cli::bulk_stdin_pipe_from_list_closes_the_selection`
- [x] failures are reported per id, best-effort — `cli::bulk_is_best_effort_and_reports_failures`
- [x] repeated ids are deduped — `cli::bulk_dedupes_repeated_ids`
- [x] space-separated ids are rejected, not silently widened — `cli::space_separated_ids_are_rejected_not_silently_widened`

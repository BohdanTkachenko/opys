# engine: interleaved id sequences

[ADR-0103 — Interleaved id sequences replace lease blocks](ADR-0103.md). Independent of the lifecycle chain.

Spec:

- `[ids] modulus = M` in `opys.toml` (validated `M >= 2`). Slot from
  `OPYS_ID_SLOT` (validated `< M`), else `hash(user@host) % M` where the hash
  is stable across runs and platforms.
- `ids::Interleaved { slot, modulus }` implements `IdSource`: the smallest `n
  ≡ slot (mod M)` with `n > max_doc_id`. `SequenceMax` remains the source
  when no modulus is configured, byte-identically.
- Construction moves behind `Ctx` (the [FEAT-0081 — ID lease blocks in an orphan git ref](FEAT-0081.md) prerequisite); `new`,
  `import` and `renumber` allocate through it.
- On acceptance of [ADR-0103 — Interleaved id sequences replace lease blocks](ADR-0103.md): [ADR-0055 — ID allocation: local lock, lease blocks in a ref, renumber as repair](ADR-0055.md) to `superseded` with a reference,
  [FEAT-0081 — ID lease blocks in an orphan git ref](FEAT-0081.md) to `wontfix` with the ADR as the reason.
- format.md: the ids section documents modulus, slot, gaps and the `pad`
  guidance; the skill's loop page tells orchestrators to set a slot per agent.

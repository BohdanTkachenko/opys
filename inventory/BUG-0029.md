# linkify rewrites double-backtick code spans and hyphenated tokens

## Reproduction
Body prose ``[FEAT-0002 — Global never-reuse ID sequence and retired ledger](FEAT-0002.md)`` (double-backtick span) gets linkified after `opys sync` — the even/odd backtick parity heuristic in `src/links.rs` only handles single-backtick spans, contradicting format.md's "code spans are never re-linkified". Separately, `Branch FEAT-0001-fix-login here.` becomes a link plus `-fix-login` residue because the `\b` boundary matches inside hyphenated tokens; and the fence tracker toggles on any ```/~~~ line, so mixed or nested fences flip state (indented code blocks are not skipped at all).

# opys-server: scaffold the AGPL crate

First step of the [FEAT-0058 — opys-server: the always-on node](FEAT-0058.md) build. Read [FEAT-0058 — opys-server: the always-on node](FEAT-0058.md)'s **Implementation
guardrails** section before writing any code; they apply to every task in this
chain.

Create the `opys-server` workspace crate: a new binary, **licensed
AGPL-3.0-only** per [ADR-0056 — License split: Apache-2.0 core, AGPL server components](ADR-0056.md) (the rest of the workspace stays Apache-2.0), not
published yet. The Apache `opys` binary and `opys-engine` must NOT gain any
dependency on this crate, ever — that direction would drag the CLI under AGPL.
Dependencies flow one way: opys-server → engine/backend.

Spec:

- New dir `opys-server/`, workspace member in the root `Cargo.toml`.
- `opys-server/Cargo.toml`: `name = "opys-server"`, `version.workspace = true`,
  `edition = "2021"`, `rust-version = "1.88"`, `license = "AGPL-3.0-only"`,
  `publish = false` (flipped at the M2 milestone, not before), description
  "Always-on opys node: watcher, HTTP/WS API, and web UI over local
  inventories". Copy the repository/readme fields style from the other crates.
- `opys-server/LICENSE`: the full GNU AGPL-3.0 text. `opys-server/README.md`:
  a short crate README noting the license split (tool Apache, server AGPL) and
  pointing at the project README.
- Dependencies (pin these; do not add others without need):
  `opys-engine = { path = "..", version = "0.12" }`,
  `opys-backend-markdown-local = { path = "../opys-backend-markdown-local", version = "0.12" }`,
  `axum = { version = "0.8", features = ["ws"] }`,
  `tokio = { version = "1", features = ["rt-multi-thread", "macros", "net", "sync", "time"] }`,
  `notify = "8"`, `clap = { version = "4", features = ["derive"] }`,
  `serde = { version = "1", features = ["derive"] }`, `serde_json = "1"`,
  `comrak = "0.52"`. Dev-deps: `tempfile = "3"`, `tower = { version = "0.5", features = ["util"] }`,
  `http-body-util = "0.1"`.
- `src/main.rs`: clap derive with subcommands `run` (default when omitted),
  `install`, `uninstall`. `run` takes `roots: Vec<PathBuf>` (≥1 required) and
  `--bind <ADDR>` (default `127.0.0.1:6797`). For this task, `run` starts an
  axum server on the bind address serving exactly one route,
  `GET /api/health` → `{"ok":true,"version":"<CARGO_PKG_VERSION>"}`, and logs
  one line to stderr: `opys-server listening on http://<addr>`. `install`/
  `uninstall` exit 2 with "not implemented yet ([TASK-0075 — opys-server: systemd install, docs, and M1 closeout](TASK-0075.md))".
- If release-plz's next run objects to the unpublished member, add the
  crate with `release = false` in `release-plz.toml` (precedent: commit
  4a749bf).
- Update AGENTS.md and CLAUDE.md: the workspace is now four crates; state the
  license boundary sentence ("`opys-server` is AGPL-3.0-only; nothing
  Apache-side may depend on it").
- Run the `msrv` devShell command; if any new dependency raises the floor
  above 1.88, pin an older major/minor of that dependency instead of bumping
  the MSRV.

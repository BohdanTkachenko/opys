# Bundle management-plane AI; execution-plane AI is bring-your-own

## Context

The web/mobile UI needs native AI features ([FEAT-0064 — Planning assistant: AI over the typed API](FEAT-0064.md)): plan a project,
decompose an epic, draft docs, summarize what the fleet did overnight. Relying
on the user wiring up MCP from a vendor chat app is not a native experience.
"Reselling AI" was rejected earlier — but that rejection was about selling
*general model access* (opys as your Claude replacement: pooled subscriptions,
price war with vendors, margin sink). Inference embedded in a product feature
is a different thing entirely: token COGS, exactly like the VM COGS accepted
in [ADR-0053 — Everything open source; sell connectivity, hosting, and convenience](ADR-0053.md), and the explicitly intended use of vendor commercial APIs. The
cost asymmetry is decisive: planning/drafting burns cents per user per day;
coding agents grinding through tasks burn dollars per hour.

## Decision

Split by plane. **Management-plane AI** (the planning assistant and its kin —
anything that operates on the registry through the typed API) ships in the
open-source product with a bring-your-own API key, and paid tiers bundle a
metered credit allowance so it works with zero setup. **Execution-plane AI**
(the coding agents the orchestrator runs) is always the user's own keys and
subscriptions, on their nodes or their Hosted VM. Never an "unlimited AI"
plan (Cursor's 2025 pricing collapse is the standing cautionary tale). And an
absolute prohibition: consumer-subscription credentials present on a Hosted VM
(e.g. Claude Code OAuth tokens) are licensed for that product and must never
be routed through to power opys app features — assistant inference goes
through API keys (the user's or our metered allowance) only.

## Consequences

- The model-access layer in [FEAT-0064 — Planning assistant: AI over the typed API](FEAT-0064.md) needs two paths from day one: user key
  and bundled allowance; self-hosters get full capability with their key,
  preserving [ADR-0053 — Everything open source; sell connectivity, hosting, and convenience](ADR-0053.md)'s no-feature-gating rule.
- Using the *hosted* assistant is a consented, feature-scoped exception to
  relay blindness ([ADR-0052 — The hosted plane is blind and unprivileged](ADR-0052.md)): the docs it reads pass through our plane and the
  model vendor; disclose per-feature, and offer node-side inference for E2E
  purists.
- Bundled credits are a metered line item next to compute — same billing
  machinery, same never-unlimited rule.
- opys stays out of competition with the agent vendors it orchestrates; the
  coordination-layer AI is ours, the coding-layer AI is theirs.

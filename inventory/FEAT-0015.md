# Ephemeral work items: close and cleanup

Work-item types (task/bug/chore in the default config) are scratchpads: they must link to a feature, and `close` finishes them — the file is deleted, the terminal status recorded, and inbound references become struck-through tombstones that keep reserving the id. `cleanup` strips struck refs once nobody needs the history. Durable knowledge lives in features; the task board is disposable.

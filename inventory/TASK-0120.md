# opys-server: the flow graph view

[FEAT-0109 — Flow graph view: statuses as nodes, agents as loops](FEAT-0109.md). Depends on [TASK-0119 — opys-server: ref reader, occupancy in the union, `next` endpoint, autofix](TASK-0119.md).

Spec:

- `Flow.svelte`: nodes from the union of every type's statuses, merged by
  name; edges from the union of transitions (the API exposes the type config
  needed, read from main's `opys.toml`). Layout is layered left to right from
  initial statuses; disconnected components stack. No graph library: a small
  layered layout in `lib/flow.js`, tested.
- Each node fetches `next` per type present with the node's `limits`, lists the
  items, shows the blocked count, and draws occupancy chips per item with a
  stuck mark from the API's flag.
- `human = true` nodes render as gates. Clicking an item routes to the document
  view.
- Re-render on `corpus-reloaded` and `refs-changed`.
- `ui-build`, commit `dist/`, and the drift job stays green.

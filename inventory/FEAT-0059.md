# Relay and Connect: remote access to your nodes

The hosted plane and the ~$5/mo **Connect** tier ([ADR-0053 — Everything open source; sell connectivity, hosting, and convenience](ADR-0053.md)): a node dials
*out* to the relay over persistent WSS (no NAT/port-forwarding), clients (web
app, phone, later MCP [FEAT-0042 — Remote MCP: manage the registry from shell-less hosts](FEAT-0042.md)) authenticate to the relay, and the relay
routes end-to-end-encrypted traffic between them ([ADR-0052 — The hosted plane is blind and unprivileged](ADR-0052.md) — identity,
presence, ciphertext routing; nothing else). The Nabu Casa model: the money
buys connectivity, never captivity. **This is the announcement milestone
([ADR-0057 — One announcement, at the relay milestone](ADR-0057.md)).**

Components:

- `opys auth login` — device-code flow; registers the node to the account.
  Multi-node per account, multi-project per node from day one (the same
  machinery is the [FEAT-0063 — Teams: node mesh, union view, per-seat plan](FEAT-0063.md) team mesh at N=1).
- **Relay service** — account/auth, node registry + presence, WSS routing,
  hosted web app (the [FEAT-0058 — opys-server: the always-on node](FEAT-0058.md) UI served from our domain, talking through
  the relay to the user's nodes).
- **E2E layer** — node↔client keys the relay never holds; device enrollment,
  rotation, and recovery are core protocol work, designed before v1 ships.
- **Offline continuity** — the node uploads an *encrypted* last-known
  snapshot; when the laptop sleeps, clients show it stale-labeled and
  decrypt client-side. The relay stays blind.
- **Capability scope** — typed API only to BYO hardware; no shell transport
  ([ADR-0052 — The hosted plane is blind and unprivileged](ADR-0052.md)). The API is the support boundary: if the node speaks it, the
  service works; everything behind it is the user's.

Self-hosters run the relay themselves (it is open source, [ADR-0053 — Everything open source; sell connectivity, hosting, and convenience](ADR-0053.md); license
question [ADR-0056 — License split: Apache-2.0 core, AGPL server components](ADR-0056.md)) or skip it entirely (tailnet/VPN to their node).

## Test plan
- [ ] a node behind NAT is reachable from the hosted web app with no inbound configuration
- [ ] relay-side storage and traffic contain no plaintext registry content (E2E verified end to end)
- [ ] a revoked device loses access; a revoked node disappears from the account
- [ ] snapshot continuity: node offline → clients see stale-labeled last-known state, decrypted client-side
- [ ] no relay endpoint can deliver arbitrary command execution to a node
- [ ] self-hosted relay: the same client + node pair works against an operator-run relay

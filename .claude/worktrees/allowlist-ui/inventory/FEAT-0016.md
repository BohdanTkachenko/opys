# Code references: file_refs and show --refs

`[file_refs]` declares how document ids are spelled in code (`FEAT-0001`, `FEAT1`, `feat_1`, …) via render templates. `opys show <id> --refs` scans the configured roots for textual mentions, and `renumber` warns (with `sed` fix-ups) when a renumbered id is still referenced.

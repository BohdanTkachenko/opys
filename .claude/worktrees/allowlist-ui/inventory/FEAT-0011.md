# Configurable stats

`opys stats` renders the config's `[[stats]]` sections — each one SQL query over the corpus tables, shown as a markdown table or through a per-row `template`. The default config ships status-by-type, test-plan coverage, and tag summaries; `verify` type-checks every configured query so a broken stat fails CI, not the reader.

# Layout templates and canonical relocation

A document's path under the base is rendered from the `[layout]` template (`{type}`/`{status}`/`{id}` segments; empty segments collapse, so docs live flat by default). The sync pass relocates each document to its canonical path when a status change or layout edit moved it — e.g. archived features into `_archived/`.

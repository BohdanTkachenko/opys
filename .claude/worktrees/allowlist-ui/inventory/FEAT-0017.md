# renumber: cross-branch ID collision repair

Two branches can each allocate the same id; `opys renumber` resolves the collision after merge by keeping the id that existed at the merge base and renumbering the branch-added doc, then warning about stale code references with `sed` suggestions.

Partial because the core keep/renumber resolution is untested, relocated docs can be misclassified as branch-added, and rewriting is a raw substring replace with no word boundary.
